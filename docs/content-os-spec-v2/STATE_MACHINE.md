# STATE MACHINE

## Asset
NEW
-> VALIDATING
-> READY
-> RESERVED
-> PROCESSING
-> GENERATED
-> ARCHIVED

Errores:
MISSING_DESCRIPTION
FAILED_SYNC
FAILED_PROCESSING

## Publication
DRAFT
-> PENDING_APPROVAL
-> APPROVED
-> SCHEDULED
-> PUBLISHING
-> PUBLISHED

Alternativas:
PENDING_APPROVAL -> REJECTED
APPROVED -> CANCELLED
SCHEDULED -> PAUSED
PUBLISHING -> FAILED
FAILED -> RETRY_SCHEDULED -> PUBLISHING

## Idempotencia
publication.idempotency_key debe impedir posts duplicados.
