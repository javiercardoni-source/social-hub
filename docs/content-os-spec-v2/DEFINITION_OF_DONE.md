# DEFINITION OF DONE

Cada feature debe tener:
- implementación;
- tests;
- estados de error;
- logs;
- documentación;
- manejo offline cuando aplique;
- integración con backup;
- seguridad.

El MVP termina cuando funciona:

Empleado
-> Sistema de Conteo de Horas y Turnos
-> Drive
-> Content OS
-> IA
-> generación
-> Drive
-> aprobación
-> scheduler
-> publicación
-> audit log
-> backup.
