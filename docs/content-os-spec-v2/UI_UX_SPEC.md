# UI / UX SPEC

## Objetivo visual
La aplicación debe sentirse:
- moderna;
- alegre;
- intuitiva;
- clara;
- premium;
- fácil de usar diariamente.

Evitar estética de ERP gris y pesada.

## Navegación
- Inicio
- Biblioteca
- Campañas
- Calendario
- Aprobaciones
- Programados
- Publicados
- Alertas
- Configuración

## Inicio
Cards:
- Nuevos contenidos
- Pendientes
- Programados esta semana
- Cuentas conectadas

Bloques:
- calendario semanal;
- aprobación rápida;
- contenido nuevo de empleados;
- estado Drive;
- backup;
- modo seguro.

## Biblioteca
Vista en cards.
Cada asset:
- thumbnail;
- descripción;
- origen;
- empleado;
- estado;
- calidad;
- tags;
- campaña sugerida.

## Calendario
Drag & drop.
Filtros:
- plataforma;
- campaña;
- cuenta;
- estado.

## Aprobación
Mostrar:
- media;
- caption;
- hashtags;
- fecha;
- plataforma;
- campaña;
- versión;
- warnings.

Botones:
- Aprobar
- Editar
- Regenerar
- Rechazar
- Reprogramar
